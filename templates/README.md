# templates

`manual-template.md` はマニュアルの雛形です。

## 組み立てのルール

- **見出し構成は固定**です。順番も変えません。
- 担当者が「この項目は不要」と明言したセクションのみ、省いて構いません。
- 手順の各ステップは「〜する」の**動詞止め**で統一します。
- **1ステップ1動作**にします。「Aを開いてBを入力して保存する」は3ステップに分けます。
- 分からない項目は空欄にせず `（要確認）` と書きます。
- 画像・スクリーンショットは扱いません。必要な場合は、投稿後に DocBase の画面から追加してもらいます。
- `最終更新` にはその日の日付（YYYY-MM-DD）を入れます。
